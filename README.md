# GusCard 📱

**GusCard** — это цифровой кошелек для дисконтных и скидочных карт. Приложение позволяет хранить все ваши пластиковые карты в одном месте, всегда иметь под рукой их штрих-коды и получать быстрый доступ к скидкам.

## ✨ Основные возможности

*   **Сканирование:** Распознавание штрих-кодов через камеру или загрузку фото из галереи (на базе ZXing).
*   **Локальное хранение:** Все данные сохраняются в базе данных устройства (Room). Приложение работает полностью офлайн.
*   **Умный поиск:** Автодополнение названий популярных магазинов с автоматической подстановкой категорий и логотипов.
*   **Кастомизация:** Выбор цвета карты, формата штрих-кода, добавление скидок, срока действия и комментариев.
*   **Удобный просмотр:** Экран показа штрих-кода с автоматическим повышением яркости экрана (для лучшего считывания сканерами на кассах).
*   **Современный UI:** Дизайн в стиле iOS с поддержкой светлой и темной тем, а также фильтрацией по категориям (Продукты, Шопинг, АЗС и др.).

## 🛠 Технологический стек

*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **База данных:** Room (SQLite) + KSP
*   **Навигация:** Jetpack Navigation Compose
*   **Сканирование ШК:** ZXing (`journeyapps:zxing-android-embedded`)
*   **Генерация ШК:** ZXing Core (`MultiFormatWriter`)
